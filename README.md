# National-Payment-Switching-Platform-Payment-Switching-Clearing-Settlement-Platform-

A highly available interbank payment switching platform that securely receives electronic transactions from participating financial institutions, 
validates and routes them to the appropriate destination institution, processes transaction responses, and provides settlement/reconciliation capabilities.
